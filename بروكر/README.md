# Broker Website Wireframe

هذا مجلد موقع ثابت مناسب للرفع على GitHub Pages.

## التشغيل المحلي

افتح الملف التالي مباشرة في المتصفح:

`wireframe/index.html`

## الرفع على GitHub Pages

يمكن رفع كامل هذا المجلد إلى GitHub Pages من جذر المستودع. ملف `index.html` الموجود في الجذر يحول الزائر تلقائياً إلى:

`wireframe/index.html`

## الصور

ضع الصور داخل:

`wireframe/assets/images`

وتجد أسماء الصور المقترحة في:

`wireframe/assets/images/README.md`
