# Broker Website Images

ضع الصور النهائية داخل هذا المجلد حتى تعمل بسهولة على GitHub Pages.

## الصور الرئيسية

- `home-hero.jpg`: صورة الصفحة الرئيسية، ويفضل أن تكون لقطة واسعة لمعدات ثقيلة أو منصة نفطية.
- `about-company.jpg`: صورة صفحة عن الشركة، مثل مقر الشركة أو فريق العمل أو موقع مشروع.

## ملاحظات سريعة

- استخدم أسماء ملفات إنجليزية بدون فراغات حتى تبقى الروابط ثابتة على GitHub Pages.
- الصور المقترحة للـ hero يفضل أن تكون بعرض 1600px أو أكثر.
- الشعارات بصيغة PNG أو SVG تكون أنظف للشبكة.
